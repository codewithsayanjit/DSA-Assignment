# 🤝 Contributing

This repository is primarily maintained for my **college Data Structures and Algorithms Lab assignments**.

Suggestions, corrections, optimizations, and improvements are welcome.

### How to Contribute

1. **Fork** this repository.
2. Create a new branch.

```bash
git checkout -b feature/improvement
```

3. Make your changes.
4. Check your code and test the program.
5. Add and commit your changes.

```bash
git add .
git commit -m "Improve DSA assignment program"
```

6. Push your branch.

```bash
git push origin feature/improvement
```

7. Open a **Pull Request**.

### Contribution Guidelines

- Keep the existing assignment folder structure.
- Use meaningful program and variable names.
- Add comments where necessary.
- Test programs before submitting a contribution.
- Do not remove existing assignment programs.
- Keep each question in its respective `Q1.c`, `Q2.c`, etc. file.
